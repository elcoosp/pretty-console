This guide shows how to define a reusable `Style`, apply it to different
texts, and combine styles without duplicating attributes. It assumes you
already install the crate and print spans — see
[Getting started](/tutorials/getting-started/) if you do not.

## Define a style once

`Style` is `Copy` and `const`-constructible, so a style can live in a `const`
or `static` and never allocate:

```rust
use pretty_console::{Color, Style};

const HEADING: Style = Style::new().bold().underline().fg(Color::BRIGHT_BLUE);

HEADING.paint("Chapter 1").println();
HEADING.paint("Chapter 2").println();
```

`Style::paint(text)` produces a ready-to-print [`Span`](/reference/span/).

## Apply it to different text

When you already hold a styled [`Span`](/reference/span/) and want to keep its
style but change the text, use `with_text`:

```rust
use pretty_console::{Span, Styled};

let error = Span::new("").red().bold();
error.with_text("Error 1: Something went wrong").println();
error.with_text("Error 2: Another issue").println();
```

## Merge two styles

`merge` combines two styles: colors set by the argument win, and attribute
sets are unioned — duplicates are impossible because attributes live in a
bitset:

```rust
use pretty_console::{Color, Style};

let heading = Style::new().bold().underline().fg(Color::BRIGHT_BLUE);
let emphasis = Style::new().fg(Color::RED);

// Red wins; bold and underline stay.
heading.merge(emphasis).paint("Important").println();
```

This is the rule to remember when layering a base style with an override:
the override's foreground and background replace the base's, attributes from
both sides are kept.

## Convert colors and attributes into styles

`Style` implements `From<Color>`, `From<Attribute>` and `From<Effects>`, so
single-purpose values convert directly:

```rust
use pretty_console::{Attribute, Color, Style};

let colored = Style::from(Color::CYAN);
let tilted = Style::from(Attribute::Italic);
```

## Adjust conditionally with `when`

`when` keeps builder chains flat instead of forcing `if` statements around
them:

```rust
use pretty_console::{Color, Style};

let verbose = std::env::var("VERBOSE").is_ok();
let style = Style::new().when(verbose, |s| s.fg(Color::CYAN).dim());
```

The closure runs only when the condition holds; otherwise the style passes
through untouched. [`Span`](/reference/span/) and
[`Line`](/reference/line/) have the same `when` method.
