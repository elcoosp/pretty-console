This guide shows how to build a single row out of differently styled segments,
how the styling methods attach to segments, and how to align whole lines. It
assumes you can already print a styled [`Span`](/reference/span/).

## Push segments left to right

[`Line`](/reference/line/) collects spans and renders them as one row. Push a
segment, then style it — the styling methods always apply to the **last
pushed** segment:

```rust
use pretty_console::Line;

let line = Line::new()
    .push("  build ").dim()
    .push("cargo build --release").bold()
    .push(" finished in ").push("4.2s").green();
line.println();
```

Read the chain as a cursor: `.push("...")` moves the cursor to a new segment;
`.dim()`, `.bold()` and `.green()` restyle the segment under the cursor. The
connector `" finished in "` gets no styling calls, so it stays plain.

## Understand the last-span rule

Because styling applies to the last pushed segment, the order of `push` and
style calls decides what gets colored:

```rust
use pretty_console::Line;

// Red applies to "world", not to "hello ".
let line = Line::new().push("hello ").push("world").red();
```

If you style before pushing anything, the line creates an empty trailing
segment and styles that — harmless, but pointless. Style after the `push`
whose segment you mean to color.

## Build a line from an iterator

For segments that already exist as spans, construct directly:

```rust
use pretty_console::{Line, Span, Styled};

let spans = vec![
    "status: ".styled(),
    Span::new("ok").green().bold(),
];
let line = Line::from_spans(spans);
```

`Line` also implements `FromIterator<Span>` and `From<Vec<Span>>`, so
`collect()` works on span iterators.

## Restyle every span at once

`with_style` merges a style into **every** span of the line; the merged
style's colors win over per-span colors, attributes are unioned:

```rust
use pretty_console::{Line, Style};

let line = Line::new().push("a ").push("b").red();
let dimmed = line.with_style(Style::new().dim());
```

`map_span` rewrites each span through a closure when you need per-span logic.

## Accumulate in a loop

In loops, collect the row by reassigning the builder — [`Line`](/reference/line/)
methods consume and return the line (`push_mut` appends in place when you do
not need to style the new segment):

```rust
use pretty_console::Line;

let mut line = Line::new();
for (name, ok) in [("fmt", true), ("clippy", true), ("tests", false)] {
    line = line.push(name);
    if ok {
        line = line.push(" ✓").green();
    } else {
        line = line.push(" ✗").red();
    }
    line = line.push("  ");
}
line.println();
```

## Align a whole line with format widths

`Display` for `Line` pads by the line's **visible** width — ANSI escapes and
wide CJK characters are measured the way a terminal renders them:

```rust
use pretty_console::Line;

let line = Line::new().push("cache ").push("warm").green();
println!("{:<20}|", line);
```

Left, right and center alignment follow the standard format spec, and the
padding is computed from visible columns — so columns line up even when the
segments contain escapes or CJK text.
