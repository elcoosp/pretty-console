title: Degrade colors
description: Detect the terminal's color capability and render truecolor content as 256-color or 16-color output.

This guide shows how to detect what a terminal can display and how to render
truecolor content at a lower capability level. Use it when output must survive
CI logs, `ssh` sessions or IDE consoles that only understand a subset of ANSI
colors. For turning colors off entirely, see
[Control colors at runtime](/guides/runtime-color-control/).

## Detect the terminal capability

`supports_color_level()` inspects `FORCE_COLOR`, `CLICOLOR_FORCE`, `NO_COLOR`,
`CLICOLOR`, `TERM` and `COLORTERM`, then falls back to stdout detection. It
returns `None` when no colors should be emitted at all:

<Code lang="rust" code={`use pretty_console::{supports_color_level, ColorLevel};

match supports_color_level() {
    Some(ColorLevel::TrueColor) => println!("terminal can display everything"),
    Some(level) => println!("terminal degrades to {level:?}"),
    None => println!("no colors at all"),
}`} />

## Render a span or line at a level

`render_with` reduces every color of the styled value to the richest
representation the level supports. Unlike `render`, it exists for exactly this
situation — pre-degrading before you ship the string somewhere else:

<Code lang="rust" code={`use pretty_console::{ColorLevel, Line, Span, Styled};

let fancy = "truecolor text".fg_hex(0x7C_4D_FF);
println!("{}", fancy.render_with(ColorLevel::Ansi256)); // nearest palette entry
println!("{}", fancy.render_with(ColorLevel::Ansi16));  // nearest of the 16 base colors

let line = Line::new().push("done ").push("fast").fg_hex(0x22_D3_EE);
println!("{}", line.render_with(ColorLevel::Ansi16));`} />

The returned string is plain text with the degraded escapes baked in — write it
to logs, a pipe or a file as-is.

## Degrade a single color

`Color` exposes the same reduction so you can render palette swatches or
legends that match the degraded output:

<Code lang="rust" code={`use pretty_console::{Color, ColorLevel};

let brand = Color::hex(0x7C_4D_FF);
let for_256 = brand.degrade_to(ColorLevel::Ansi256);
let for_16 = brand.degrade_to(ColorLevel::Ansi16);`} />

`degrade_to` keeps colors that the level can represent exactly (a base color
stays itself at `Ansi16`), maps RGB to the nearest 256-palette entry, and maps
anything to the nearest of the 16 base colors at `Ansi16`.

## Produce stable output for CI logs

Combine detection and degradation in one place, early in `main`:

<Code lang="rust" code={`use pretty_console::{supports_color_level, ColorLevel, Span, Styled};

fn render_report(body: &str) -> String {
    let level = supports_color_level().unwrap_or(ColorLevel::Ansi16);
    Span::new(body).bold().render_with(level)
}`} />

On a color-less runner, `supports_color_level()` returns `None` and the
`unwrap_or` keeps your pipeline rendering (as plain 16-color output); pick
`ColorChoice::Never` instead if you want no escapes at all — see
[Control colors at runtime](/guides/runtime-color-control/).
