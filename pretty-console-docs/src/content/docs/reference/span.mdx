`Span` is a styled string: text, a [`Style`](/reference/style/), and an
optional OSC 8 hyperlink. It derives `Debug`, `Clone`, `Default`,
`PartialEq`, `Eq`, `Hash`, and implements `Display` with visible-width
padding. The v1 name `Console` survives as a type alias. Source:
`src/span.rs`.

## Style builder methods

All builder methods consume `self` and return `Self`. Colors set the
foreground (`fg*`) or background (`bg*`, `on_*`) of the held style; attribute
methods insert into the style's [`Effects`](/reference/style/) bitset.

| Group | Methods |
| --- | --- |
| Direct setters | `fg(Color)`, `bg(Color)`, `fg_rgb(u8, u8, u8)`, `bg_rgb(u8, u8, u8)`, `fg_hex(u32)`, `bg_hex(u32)`, `attr(Attribute)`, `effects(Effects)` |
| Foreground | `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`, `bright_black`, `bright_red`, `bright_green`, `bright_yellow`, `bright_blue`, `bright_magenta`, `bright_cyan`, `bright_white` |
| Background | `on_black`, `on_red`, `on_green`, `on_yellow`, `on_blue`, `on_magenta`, `on_cyan`, `on_white`, `on_bright_black`, `on_bright_red`, `on_bright_green`, `on_bright_yellow`, `on_bright_blue`, `on_bright_magenta`, `on_bright_cyan`, `on_bright_white` |
| Attributes | `bold`, `dim`, `italic`, `underline`, `blink`, `reverse`, `hidden`, `strikethrough` |
| Conditional | `when(bool, impl FnOnce(Self) -> Self)` |

## Level helpers

The constructors `info`, `warn`, `error`, `success` and `debug` prefix the
text with a tag and apply a fixed style:

| Constructor | Tag | Style |
| --- | --- | --- |
| `info` | `[INFO]` | cyan |
| `warn` | `[WARN]` | yellow |
| `error` | `[ERROR]` | bold red |
| `success` | `[OK]` | bold green |
| `debug` | `[DEBUG]` | dim |

## Banner

`banner(title, width)` builds a horizontal rule with the centered title,
styled cyan and bold. The rule character is `─`; the title width is measured
with `chars().count()`. When `width` is too small to leave at least two
dashes on each side (fewer than 4 dashes in total), the plain title styled
cyan and bold is returned instead.

## Hyperlinks

| Method | Signature | Notes |
| --- | --- | --- |
| `link` | `pub fn link(self, url: impl Into<Box<str>>) -> Self` | Attaches an OSC 8 URL |
| `unlink` | `pub fn unlink(self) -> Self` | Removes any URL |
| `url` | `pub fn url(&self) -> Option<&str>` | The current URL |

A link renders as `ESC ]8;;URL ESC \` before the styled text and
`ESC ]8;; ESC \` after it. Links are suppressed under the `no-color` feature
and when printing with colors disabled.

## Rendering

| Method | Signature | Notes |
| --- | --- | --- |
| `render` | `pub fn render(&self) -> String` | Deterministic; never consults the environment |
| `render_with` | `pub fn render_with(&self, level: ColorLevel) -> String` | Degrades colors to `level` first |
| `write_to` | `pub fn write_to(&self, writer: &mut impl io::Write) -> io::Result<()>` | Honors `ColorChoice`; fallible |

`Display` (and therefore `to_string`) renders like `render`. When a format
width is present, padding is computed from the visible (CJK-aware) text
width, honoring the spec's fill and alignment.

## Printing

All methods below write to stdout or stderr, honoring the global
[`ColorChoice`](/reference/color-control/).

| Method | Stream | Newline | Failure |
| --- | --- | --- | --- |
| `print` | stdout | no | panics |
| `println` | stdout | yes | panics |
| `eprint` | stderr | no | panics |
| `eprintln` | stderr | yes | panics |
| `try_print` | stdout | no | `io::Result<()>` |
| `try_println` | stdout | yes | `io::Result<()>` |
| `try_eprint` | stderr | no | `io::Result<()>` |
| `try_eprintln` | stderr | yes | `io::Result<()>` |

## The Styled extension trait

`Styled` is implemented for every `T: AsRef<str> + ?Sized` and paints
string-like values in place. `styled()` wraps the value in a plain
`Span`; every other method forwards to the corresponding `Span` builder and
returns a `Span`:

<Code lang="rust" code={`use pretty_console::Styled;

let span = "hello".red().bold();`} />

The trait carries `styled`, the sixteen foreground colors, the sixteen
`on_*` backgrounds, and the eight attribute methods — the same names as the
`Span` builder tables above.

## Derives and trait impls

| Impl | Behavior |
| --- | --- |
| `Default` | Empty text, plain style, no link |
| `From<&str>`, `From<String>` | Same as `Span::new` |
| `Display` | Render with visible-width padding |

`Console` is `pub type Console = Span;`, kept for v1 compatibility.
