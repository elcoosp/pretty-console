The text utilities treat ANSI escape sequences as zero-width, skip zero-width
characters and count wide characters as two columns, so measurements match
what a terminal renders. They are dependency-free and use a practical
approximation of the `unicode-width` reference tables. Source: `src/text.rs`.

## strip_ansi

`pub fn strip_ansi(input: &str) -> String` — removes escape sequences and
returns the plain text.

Recognized sequences:

| Form | Grammar |
| --- | --- |
| CSI | `ESC [` + any number of parameter/intermediate bytes (`0x20..=0x3F`) + exactly one final byte |
| OSC | `ESC ]` + payload until `BEL` (`0x07`) or `ESC \` (ST) |
| Other | `ESC` plus exactly one following character |

Truncated sequences at the end of the input are dropped.

## char_width

`pub fn char_width(c: char) -> usize` — the number of terminal columns one
character occupies.

| Range | Width |
| --- | --- |
| Control characters `0x00..=0x1F`, `0x7F` | 0 |
| Combining diacritics and marks (e.g. `0x0300..=0x036F`, `0x0591..=0x05BD`, `0x20D0..=0x20F0`) | 0 |
| Zero-width space, ZWNJ, ZWJ, directional marks (`0x200B..=0x200F`, `0x2060..=0x2064`, `0xFEFF`) | 0 |
| Variation selectors (`0xFE00..=0xFE0F`, `0xE0100..=0xE01EF`) | 0 |
| Hangul Jamo (`0x1100..=0x115F`) | 2 |
| CJK radicals, punctuation, kana, ideographs (`0x2E80..=0x33FF`, `0x3400..=0x4DBF`, `0x4E00..=0x9FFF`) | 2 |
| Yi, Hangul jamo and syllables (`0xA000..=0xA4CF`, `0xA960..=0xA97F`, `0xAC00..=0xD7A3`) | 2 |
| CJK compatibility forms (`0xF900..=0xFAFF`, `0xFE10..=0xFE19`, `0xFE30..=0xFE6F`) | 2 |
| Fullwidth forms (`0xFF00..=0xFF60`, `0xFFE0..=0xFFE6`) | 2 |
| Emoji blocks (`0x1F300..=0x1F64F`, `0x1F900..=0x1F9FF`, `0x1FA70..=0x1FAFF`) | 2 |
| CJK extensions B and C (`0x20000..=0x2FFFD`, `0x30000..=0x3FFFD`) | 2 |
| Everything else | 1 |

This is a documented approximation chosen to keep the crate dependency-free;
it does not reach full parity with the `unicode-width` crate.

## visible_width

`pub fn visible_width(input: &str) -> usize` — the number of terminal columns
`input` occupies.

- If the input contains `ESC`, it is stripped first, then measured.
- Pure-ASCII inputs count the printable bytes `0x20..=0x7E` (a fast path).
- Otherwise the widths of the characters are summed.

## truncate

`pub fn truncate(input: &str, max_width: usize, tail: &str) -> String` — cuts
to at most `max_width` visible columns, appending `tail` when truncation
happens.

| Behavior | Detail |
| --- | --- |
| Fits | Returned unchanged (a fresh `String`) |
| Budget | Characters keep fitting while `width + char_width ≤ max_width − visible_width(tail)` |
| Escapes | Preserved and zero-width; a reset (`ESC [0m`) is appended after the tail when any escape was emitted |
| Undersized budget | When `max_width` is smaller than the tail, the tail overruns the requested width |

## pad and Align

`pub fn pad(input: &str, width: usize, align: Align, fill: char) -> String` —
pads to exactly `width` visible columns.

| Case | Result |
| --- | --- |
| Input wider than `width` | Returned unchanged — `pad` never truncates |
| `Align::Left` (default) | Fill appended on the right |
| `Align::Center` | Split, the odd column on the right |
| `Align::Right` | Fill prepended on the left |

`Align` derives `Debug`, `Clone`, `Copy`, `Default`, `PartialEq`, `Eq`,
`Hash`; `Default` is `Left`.
